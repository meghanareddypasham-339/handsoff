# HandoffOS Color System

## Core identity
- Electric Indigo: `#6D5EF7` — primary actions, navigation, active states
- Soft Lilac: `#C4B5FD` — highlights, focus, secondary accents

## Supporting palette
- Cool White: `#F7F5FF` — primary text
- Slate Lavender: `#AAA3C3` — secondary text
- Deep Ink: `#0A0818` — app background
- Indigo Charcoal: `#17132B` — cards and panels
- Cyan Mint: `#5EEAD4` — success / active agent
- Amber: `#FBBF24` — attention / paused state
- Rose: `#FB7185` — errors / destructive states
- Sky Blue: `#67E8F9` — informational accents

The core identity stays Electric Indigo + Soft Lilac. Supporting colors are used sparingly and semantically so dashboards remain polished rather than rainbow-colored.
